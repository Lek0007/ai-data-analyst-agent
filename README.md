# 🤖 Autonomous Data Analyst (Agentic AI)

An AI-powered data analyst that enables users to ask business questions in natural language and automatically generates SQL queries, executes them on a PostgreSQL database, visualizes the results, and provides business insights.

This project is being built as an end-to-end **Agentic AI Analytics Platform** to demonstrate practical skills in Generative AI, Data Analytics, SQL, PostgreSQL, and AI application development.

> 🚧 **Project Status:** Under Active Development

---

## 🚀 Features

- ✅ Natural Language to SQL using Llama 3.3 (Groq API)
- ✅ Automatic SQL Validation
- ✅ PostgreSQL Database Integration
- ✅ Dynamic Database Schema Extraction
- ✅ Automatic Business Insight Generation
- ✅ Interactive Streamlit Web Application
- ✅ Automatic Chart Generation
- ✅ Query Execution Logging
- ✅ Query History Dashboard
- 🚧 Multi-Agent AI Architecture (In Progress)
- 🚧 Report Generation (Upcoming)
- 🚧 Docker Deployment (Upcoming)
- 🚧 AWS Deployment (Upcoming)
